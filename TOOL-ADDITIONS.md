## Verification method

Every candidate was verified live before being added (search + direct site fetches, 2026-11-25):

- Official homepage/product pages confirmed live for all 54 URLs above.
- Candidates that could **not** be verified or were found pivoted/dead were **excluded**: Phind (site behind a bot wall, unverifiable), Continue (acquired by Cursor, product folded in).
- The previous audit's deliberate exclusions were respected — Sora, Tabnine, PlayHT, Windsurf (covered as "Devin Desktop"), Roo Code, Freepik AI (covered as Magnific), Duolingo Max, Gemini CLI, Hedra, Warp were **not** re-added.

## Logos

- All 54 logos were downloaded from official brand sources (apple-touch-icons, site favicons, GitHub org avatars) into `public/ai-tools/logo/png/` following the lowercase-hyphenated naming convention.
- Logos that are dark or sit on transparent backgrounds include `-dark` / `-light` variants (light-tile version for dark mode); the rest use a single file for both themes.
- All logos were visually verified against each brand; replace any you prefer with a different official asset — just keep the same file name.
